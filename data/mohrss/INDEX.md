**Collection is browser-assisted.** The site sits behind a JavaScript bot challenge that
plain HTTP clients (curl / urllib) cannot satisfy — they receive a ~1 KB cookie-setting stub
instead of the page. The attachments here were fetched through a real browser session. No
bot-detection bypass is included in this repo, so `scripts/` cannot refresh this dataset
unattended; see the README for the refresh procedure.
